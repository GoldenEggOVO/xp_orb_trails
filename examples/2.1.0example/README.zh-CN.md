# XP Orb Trails 效果收藏

[English](README.md) · [下载效果收藏 ZIP](https://github.com/GoldenEggOVO/xp_orb_trails/raw/refs/heads/26.3/examples/2.1.0example/effect_collection.zip)

这 24 套可选方案适用于 XP Orb Trails 2.1.0。打开 **方案 → 打开方案包文件夹**，放入整个 `effect_collection.zip`，点击 **文件方案 → 重新加载文件**，再选择带这个 ZIP 文件名的方案。部分效果需要水流、红石、两颗经验球或实际拾取才能看到。

## 先试这四个

| 方案 | 在游戏里怎么看 |
| --- | --- |
| **蝶群归形** | 跟着一只月蛾移动，再拾取它。观察飘落的像素如何重新拼出蛾翼。 |
| **溪流鱼群** | 让经验球沿着有水流和障碍的浅沟经过。鱼群会绕行，微粒标出水流方向。 |
| **像素浮雕** | 从侧面看飞行中的黄铜齿轮。缓慢自转时，轮齿的厚度最清楚。 |
| **原图碎裂** | 拾取红灯笼，观察带有灯笼纹样的碎片向外翻散。 |

## 飞行轨迹与动作

| 方案 | 在游戏里怎么看 |
| --- | --- |
| 笔锋拖尾 | 先直走再急转，比较直线上的细锋和转折处压宽的笔触。 |
| 截面渐变 | 从斜侧面看尾迹，沿长度寻找圆截面、六角星截面和扁带之间的过渡。 |
| 穿环回响 | 让球飞一段再拾取，看留下的蓝色圆环依次亮起、扩张。 |
| 八向飞舟 | 绕飞舟换一个观察角度，机身朝向和蓝色短尾焰更容易分辨。 |
| 关节飞翼 | 从侧面观察红褐色飞翼，翼尖比翼根晚半拍，尾部另有摆动节奏。 |
| 光入掌心 | 拾取一颗球，看金色亮点沿短弧落向手部。 |

## 碰撞、环境与多球互动

| 方案 | 在游戏里怎么看 |
| --- | --- |
| 交轨火花 | 让两颗球的飞行路线在短时间内交叉，留意交点上的金白火花。 |
| 光团融合 | 让两颗球缓缓靠近，观察琥珀色光团在它们之间连成一体。 |
| 红石脉动 | 让球经过通电红石，再断开电源，比较周围光瓣的开合与明暗。 |
| 二次落地碎雪 | 在平整硬地上拾取，冰粒第二次触地时才散出浅色雪粉。 |
| 墨迹落印 | 分别在硬地和水边拾取。前者留下不规则墨滴，后者荡开浅色环纹。 |

## 主题场景

| 方案 | 在游戏里怎么看 |
| --- | --- |
| 星轨天文台 | 侧看小行星的倾斜星环，拾取时观察星点爆开。 |
| 萤火归巢 | 夜间看萤火绕行和余光上浮，拾取时看光点收拢。 |
| 磁暴回路 | 移动时急转，观察磁场中的碎点和分叉电弧。 |
| 潮汐水镜 | 在近水面的位置拾取，观察水滴的拉伸和错时扩开的涟漪。 |
| 霜晶余迹 | 拖着冰晶走一段，尾端会碎解；在硬地拾取可看到回弹。 |
| 春日飞羽 | 交替停步和快跑，看飞鸟在悬停与滑翔之间切换。拾取时花瓣飘落。 |
| 暮雨月蛾 | 在露天黄昏或雨天飞行，观察月蛾与雨丝、尾带叠在一起的效果。 |
| 流火蜃景 | 在有纹理的墙前观察热扰动和余烬。 |
| 萤石信标 | 将球引到暗墙或地面附近，观察晶体周围的暖色光晕。 |

想修改某套效果时，在 ZIP 内的 `profiles/` 找到对应 JSON，按原目录结构重新压缩，替换同名 ZIP，再重新加载并应用方案。
