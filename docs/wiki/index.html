Your first profile

Make a moth leave a blue-to-mint trail and an expanding ring at pickup. Everything this recipe needs ships with the mod.

  1. Press the key assigned to Open Trail Settings, or use Mod Menu on Fabric or the Mods screen on Forge and NeoForge.
  2. Choose General → Open Config Folder. Create profiles/moonwake.json inside that folder and paste the example below.
  3. Choose Profiles → File Profiles → Reload Files, then select Moonwake to apply it.
  4. Open Effect Preview → Replay Animation. Collect an orb in your world to see the star-shaped trail from another angle.

Each short radius makes a groove between two points. Change all five 0.32 values to 0.7, then reload and select Moonwake again to see a softer outline.

Files & profiles

Open the config folder from the footer on the General page. The folders below are inside config/xp_orb_trails/ in your Minecraft instance.

xp_orb_trails/
├── defaults.json
├── packs/                    Downloaded ZIPs (2.1.0+)
├── profiles/                 Shareable looks
├── orb/
│   ├── effects/              JSON animations
│   └── sprites/              One folder per sprite
├── pickup/
│   ├── effects/              JSON animations
│   └── sprites/              One folder per sprite
└── trail/
    └── sprites/              Stamps and ribbon textures

An effect ID uses its JSON filename without the extension. A sprite ID uses its folder name. Asset IDs accept 1–64 lowercase letters, digits, underscores or hyphens. For example, orb/sprites/moon_moth/sheet.png is sprite:orb/moon_moth.

File profile format

FieldAccepted valuesWhat it changes
version1Required JSON format version. Use a number.
name
nameKey		Text / translation keyUse name for a fixed label, or nameKey for a translated label. The filename supplies a fallback.

A file profile starts with your defaults.json values, then applies the visual fields it supplies. Personal settings live one level up in config/xp_orb_trails.json. File profiles preserve the active master switch, render range and trail limit. An in-game saved profile captures all three. The raw settings and defaults use integer RGB colors. File profiles use quoted #RRGGBB values.

Editable starting points

Browse the installed JSON and PNG files for working examples. Try profiles/comet-pennant.json for a textured ribbon, orb/effects/twin-orbit.json for orbital motion, or pickup/effects/soft.json, ring.json and star.json in the same pickup folder for simple flashes. The Starfall profile connects a five-point trail with two particle emitters. Copy a template under a new filename and give it a name to compare both looks in game.

General & shared colors

Set the rendering budget and the palette used by geometric trails and effects. PNG artwork keeps the colors painted into the image.

Instance settings

Use General for the master switch and rendering limits. Edit point spacing and vertical offset in the main config with the game closed. All five fields belong to the instance and are outside the shareable file profile format.

FieldAccepted values / defaultWhat it changes
enabledBooleanDefault: trueMaster switch for the mod.
renderRange4–128 blocksDefault: 36Maximum viewing distance for tracked trails.
trailCap8–256, integerDefault: 96Maximum number of simultaneous trails.
pointSpacing0.03–1 blockDefault: 0.18Sampling distance along the path. Smaller spacing records points closer together.
orbYOffsetFinite number, blocksDefault: 0.175Vertical offset of the effect anchor relative to the orb.

The main config also stores savedPresets (up to 12 named color palettes) and savedProfiles (up to eight personal looks). Both can be managed in game.

Orb body

Keep the vanilla orb, layer an animation over it, or replace it with a looping sprite or a procedural effect.

FieldAccepted values / defaultWhat it changes
showVanillaOrbBooleanDefault: trueShows the original orb, including its resource-pack texture. Turn off to use replacement artwork alone.
flightEffectnone · file:orb/<id> · sprite:orb/<id>Default: noneSelect an orb animation or PNG. For example: file:orb/twin-orbit or sprite:orb/luna-moth.

To make your own orbit, copy orb/effects/twin-orbit.json to orb/effects/moon_orbit.json. Set its name to Moon Orbit and change the second layer’s middle keyframe radius from 1.05 to 2. Reload, then choose Orb Body → Orb Artwork → Moon Orbit. The five head-colored pieces now swing wider than the six tail-colored pieces.

Pixel relief detail

The optional Effect Collection includes profiles/lab-relief.json. Edit its relief object under advanced.workshop. minResolution and maxResolution set the lower and upper sampling limits on the longest side of a sprite frame. Each accepts a whole number from 2 to 64. The engine defaults are 2 and 32. pixelBudget sets the target number of sample cells shared across tracked orbs (4–16,384, default 1,200). A larger budget preserves more detail as more orbs appear.

For a Luna Moth that keeps its 24-pixel silhouette, set both resolution limits to 24. Fixed detail can cost more when many orbs are visible. Reload files and select the edited profile again to see the change.

Ribbon mapping

stretch
Fit one image from tail to head as the path grows.
tile
Repeat at a chosen length along the current path.
distribute_per_segment
Give each path segment an equal share of one image.
repeat_per_segment
Place a whole copy on every segment, whatever its length.
static
Anchor texture coordinates to accumulated travel. Existing points keep their phase as the tail expires.

Draw the tail on the left of the PNG and the head on the right. The ribbon descriptor can reserve pixels for each end.

Save this effect in pickup/effects/. In Moonwake, set pickupFlashStyle to file:pickup/moon_burst and pickupFlashSeconds to 0.45. Reload and reselect the profile. Two waves of diamonds rise, spread out and fade.

PNG & sprite sheets

A single square PNG makes a still sprite. A horizontal or vertical strip of square frames animates at 12 FPS without a descriptor.

Give each asset its own folder under orb/sprites/, pickup/sprites/ or trail/sprites/. For a grid or rectangular frames, add a JSON descriptor beside the PNG. Here, a 48 × 32 image contains six 16 × 16 frames in reading order.

FieldAccepted valuesWhat it changes
imagePNG filenameSelect an image in the same folder. With a single PNG, the filename can be inferred. For an exported atlas use meta.image.
name
nameKey		TextA fixed label or a Minecraft translation key for the artwork picker. In an exported atlas, put these fields in the atlas settings.
frameWidth
frameHeight		Positive integer pixelsSupply both dimensions. Each must divide the corresponding PNG dimension exactly.
frames1–1,024 framesFor a grid, set the number of cells to play, row by row. For an atlas, supply ordered frame entries as an array or object.
fpsGreater than 0, up to 1,000Frame rate. Defaults to 12 when per-frame timing is absent.
loopBoolean, default trueRepeat a sheet. Replacement orb sprites always loop while active. Pickup sprites always play once.
pivot[x, y] in frame pixelsAnchor relative to the original frame. Defaults to its center.

After the first keyframe, missing values carry forward. At the first frame, position, orbit and rotation begin at zero, width and height at 0.25, opacity at 1, and colors inherit from the layer.

Particle emitters

Choose when particles are born, what varies from one to the next, and how they move after emission.

Enable at least one emission source: a positive rate, a distance interval, or a timed burst. Combine them for a stream with an opening flash. Distances are in blocks and positive Y points up.

FieldAccepted valuesWhat it changes
rate0–128 particles/sContinuous emission by time. Zero disables this source.
distance0.01–64 blocksEmit at each interval traveled. Useful for evenly spaced particles along a moving orb’s path.
burstsUp to 16 {time,count} wavestime is 0–30 seconds from the start and count is 1–64 particles per wave.
directionNonzero [x,y,z]Normalized launch direction, default [0,1,0]. Each component can range from −1,000,000 to 1,000,000.
spread0–180°Half-angle of the launch cone. Try 10 for a jet or 80 for a spray.
lifetime0.01–10 sSeconds each particle lives. Accepts one value or [min,max].
speed0–32 blocks/sInitial launch speed. Accepts one value or [min,max].
size0.01–8×Particle size multiplier. Accepts one value or [min,max].
rotation
spin		−3,600 to 3,600Initial angle in degrees and spin in degrees/second. Both accept a number or [min,max].
colors1–16 hex colorsChoose a color independently at birth. Use head in the layer to pick it up.
gravity−64 to 64 blocks/s²Positive values pull particles downward. Negative values lift them.
drag0–32Slow particles over time. Zero preserves velocity apart from gravity.
spaceworld · localWorld anchors a particle at its emission point. Local moves the origin with the orb. Default: world.

In Moon Burst, try changing only spread from 45 to 10 and replay the effect. To emit along an orb’s flight, copy the file into orb/effects/, add "distance": 0.25, then select it as your orb artwork. The Starfall example includes working flight and pickup emitters.

Packs & advanced effects

A pack combines one or more profiles with the artwork they use. The optional Effect Collection for 2.1.0 has 24 profiles, including Butterfly Homecoming, River Procession and Surface Prints.

Install or update a ZIP

  1. Download the ZIP from the examples page.
  2. Choose Profiles → Open Packs Folder and place the ZIP in config/xp_orb_trails/packs/ while it is still compressed.
  3. Choose File Profiles → Reload Files and select a profile marked with the ZIP filename. To update it, replace the ZIP under the same name, reload, and apply the profile again.

Build on a working effect

Start with a profile whose trigger matches what you want to draw. Copy its JSON and artwork, then change one value and try it in your world. The Effect Collection guide lists all 24 triggers.

Orb body and pickup
Use advanced.body for a moving body and advanced.pickup for its response to collection. Spring Flight combines a bird that hovers or glides with a burst of falling petals.
Trails and scene conditions
Use advanced.trail for trail geometry and advanced.scene for reactions to nearby orbs, blocks, water or sound. The Tideglass profile shows how to set up water ripples.
Workshop and optics
Use advanced.workshop for effects such as decals, sprite fragments and crossing trails. Surface Prints leaves ink on solid ground and rings on water. For light or heat distortion, look at advanced.optics in Glowstone Beacon or Ember Mirage.

Give a profile a translated name

Use a nameKey shared by your profile and your Minecraft resource pack. For example, use my_pack.profile.moonwake in the profile, then give it an English value in assets/my_pack/lang/en_us.json and a Chinese value in assets/my_pack/lang/zh_cn.json. Put the resource pack in Minecraft’s resource packs folder and enable it. The player can then switch languages in Minecraft. A fixed name lets you keep a single label across languages.

Orb, trail and pickup sprites can also have translated names. Use nameKey at the root of a grid descriptor or in meta.pixelfx for a packed atlas. A PNG-only sprite looks up sprite.xporbtrails.<folder-name>. Version 2.1 recognizes original English labels in older built-in files and official examples. A label you have edited keeps your spelling.

Test & share

Reload edited files, apply the profile again, then replay the preview and collect an orb in a world.

My file is missing from the menu.
Check the reload result and logs/latest.log. File profiles and drawn effects require strict JSON with "version": 1. Check the role, duplicate or unknown keys, and hex color spelling. An invalid edit to an existing effect or sprite can leave its last working version visible.
The original orb is still visible.
Check Show Vanilla Orb and the artwork ID. An orb outside the tracking range or count limit can use the vanilla body. Turning the vanilla body off and deliberately selecting no artwork hides it.
The sheet is rejected.
Check frame dimensions, the filename, and atlas trim information. Each sheet supports up to 1,024 frames, 4,096 pixels per side and 4,194,304 pixels total. Use at most one descriptor per folder. The library supports 64 atlases and 16,777,216 pixels combined.
Some particles disappear in a large burst.
Each effect has a geometry budget of 96 pieces across up to eight layers. Rings, arcs and radial shapes spend several pieces per copy. An emitter keeps at most 64 live particles with a 384-quad budget. Reduce copies or segments to keep more particles visible.
How do I send my look to another player?
Put your JSON files in profiles/ and your custom artwork under orb/, pickup/ or trail/. Zip those folders together at the top level. One ZIP can include multiple profiles. Keep the filename when sharing an update.
How do I use a ZIP pack?
Choose Profiles → Open Packs Folder in the footer and put the ZIP there. Click Reload Files and select a profile labeled with the pack filename. Replace the ZIP to update it, or remove it to uninstall, then reload and select a profile.
