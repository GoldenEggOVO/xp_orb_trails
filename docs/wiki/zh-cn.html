制作第一个方案

给月蛾加一条由蓝色过渡到薄荷绿的尾迹，再让拾取时出现一个扩散的圆环。这个示例用到的素材均随模组提供。

  1. 按下绑定到 打开尾迹设置的按键，或在 Fabric 上使用 Mod Menu，在 Forge、NeoForge 上从模组列表进入设置。
  2. 选择 通用 → 打开配置文件夹。在这个目录下新建 profiles/moonwake.json，粘贴下方示例。
  3. 选择 方案 → 文件方案 → 重新加载文件，然后点选 Moonwake 应用这个方案。
  4. 打开 效果预览 → 重播动画。也可以在世界里拾取经验球，换个角度观察星形尾迹。

每个较短的半径都会在两个尖角之间形成凹槽。把五处 0.32 都改为 0.7，重新加载文件并再次选择 Moonwake，观察轮廓如何变得圆润。

文件与方案

在「通用」页底部打开配置文件夹。下列目录都位于当前游戏实例的 config/xp_orb_trails/ 中。

xp_orb_trails/
├── defaults.json
├── packs/                    下载的 ZIP (2.1.0+)
├── profiles/                 可分享的外观方案
├── orb/
│   ├── effects/              JSON 动画
│   └── sprites/              每套图集使用独立目录
├── pickup/
│   ├── effects/              JSON 动画
│   └── sprites/              每套图集使用独立目录
└── trail/
    └── sprites/              尾迹图案与光带纹理

效果 ID 取自 JSON 文件名，省略扩展名。图集 ID 取自目录名。素材 ID 支持 1～64 个小写英文字母、数字、下划线或连字符。例如， orb/sprites/moon_moth/sheet.png 对应 sprite:orb/moon_moth。

文件方案格式

字段可用值作用
version1必填。使用数字表示 JSON 格式版本。
advanced对象，可省略参见扩展参数表，设置本体、尾迹、拾取、场景、光学和工坊效果。
name
nameKey		文本／翻译键可以设置固定名称或翻译键。缺少显示名称时采用文件名。

文件方案先读取 defaults.json 里的初始值，再应用方案中指定的外观字段。个人设置存放在上一级的 config/xp_orb_trails.json。切换文件方案会保留当前总开关、渲染距离和尾迹数量上限，游戏内保存的个人方案则会记录这三项。主配置和默认设置以整数保存 RGB 颜色，文件方案使用带引号的 #RRGGBB 颜色值。

从已有模板开始

已安装的 JSON 和 PNG 可以直接作为参考。连续贴图光带可参看 profiles/comet-pennant.json，轨道运动可参看 orb/effects/twin-orbit.json。拾取闪光的示例包括 pickup/effects/soft.json、 ring.json 和 star.json。星落方案将五角星尾迹和两个粒子发射器组合在一起。想比较改动前后的效果，可以复制模板，换一个文件名和显示名称，然后回到游戏里切换。

通用设置与配色

设置渲染上限，以及几何尾迹与效果使用的配色。PNG 图案保留图片自身的颜色。

当前游戏实例的设置

总开关和渲染上限位于「通用」页。要调整采点间距或垂直偏移，请关闭游戏后编辑主配置。这五个字段由当前游戏实例保存。

字段可用值与默认值作用
enabled布尔值默认 true模组总开关。
renderRange4～128 格默认 36经验球尾迹的最大可见距离。
trailCap8～256 的整数默认 96同时跟踪的尾迹数量上限。
pointSpacing0.03～1 格默认 0.18沿路径的采点距离。数值越小，相邻点越密。
orbYOffset有限数值，单位为格默认 0.175效果相对于经验球中心的垂直偏移。

主配置还保存 savedPresets （最多 12 组命名配色）和 savedProfiles （最多 8 个个人方案）。两者都可以在游戏里管理。

经验球本体

可以保留原版经验球、叠加一层动画，也可以用循环图集或程序绘制的效果替换本体。

字段可用值与默认值作用
showVanillaOrb布尔值默认 true显示原版经验球，包括资源包提供的材质。关闭后可单独显示替换图案。
flightEffectnone · file:orb/<id> · sprite:orb/<id>默认 none选择经验球的动画或 PNG，例如 file:orb/twin-orbit 或 sprite:orb/luna-moth。
orbScale0.25–4×默认 1自定义经验球图案的尺寸。

要制作自己的轨道动画，将 orb/effects/twin-orbit.json 复制到 orb/effects/moon_orbit.json。把它的 name 改成 Moon Orbit，再将第二层中间关键帧的轨道半径从 1.05 调到 2。重新加载，然后选择 经验球本体 → 本体图案 → Moon Orbit。现在使用起始色的五个部件，会比使用末端色的六个部件摆得更远。

像素浮雕的细节

可选效果收藏中带有 profiles/lab-relief.json。在这个文件中找到 relief 对象，它位于 advanced.workshop。 minResolution 和 maxResolution 分别设置精灵单帧长边的最低和最高采样分辨率。两项均取 2 到 64 的整数，默认分别为 2 和 32。 pixelBudget 设置所有已追踪经验球共用的目标采样格数（4–16,384，默认 1,200）。同时出现的经验球越多，提高这个值越有助于保留细节。

若要保留月蛾原有的 24 像素轮廓，请将两个分辨率限值都设为 24。同时显示许多经验球时，固定分辨率可能增加渲染开销。重新加载文件，再次选择编辑过的预设，即可查看变化。

ribbonMapping见下方五种模式默认 stretch沿轨迹映射 PNG 的横轴。若精灵单独定义了头尾，中段使用描述文件指定的映射方式。

飘带纹理映射

stretch
轨迹延长时，将一整张图从尾部拉伸到头部。
tile
沿当前轨迹按指定长度重复纹理。
distribute_per_segment
将一张图均分给各个轨迹段。
repeat_per_segment
在每个轨迹段上铺满一整张图，与该段长度无关。
static
依据已移动的总距离确定纹理坐标。尾部逐渐消失时，其余轨迹点的纹理位置保持稳定。

将尾部画在 PNG 左侧，头部画在右侧。通过 飘带描述文件 可分别为两端预留像素。

拾取效果

选择经验球被拾取瞬间的效果，例如柔光、圆环、星形碎片、精灵动画或迸发的粒子。

字段可用值与默认值作用
pickupFlash布尔值默认 true启用拾取效果。
pickupFlashStylefile:pickup/<id> · sprite:pickup/<id>默认 file:pickup/soft选择效果文件或图集。例如 file:pickup/ring 或 sprite:pickup/collect-burst。
pickupFlashSize
pickupFlashStrength		大小 0.02–8.34 · 强度 0.1–2默认 0.65 / 0.55调整拾取效果的大小和强度，两项均独立于拖尾宽度。
pickupFlashSeconds0.08–1 秒默认 0.22关键帧拾取动画的持续时间。拾取精灵按自身帧时长播放一次，发射出的粒子各有自己的寿命。
shardCount3–16，整数默认 6图层的副本数绑定到 shardCount 时，使用这里设置的数量。
spiralTurns0.15–2默认 0.65图层的 turns 字段绑定到 spiralTurns 时，使用这里设置的旋转圈数。

示例：两波拾取粒子

将此效果保存在 pickup/effects/。在 Moonwake 预设中，将 pickupFlashStyle 设为 file:pickup/moon_burst，并将 pickupFlashSeconds 设为 0.45。重新加载并再次选择此预设，即可看到两波菱形粒子依次升起、散开并淡出。

PNG 与精灵图集

单张正方形 PNG 可作为静态精灵。若多个正方形帧横向或纵向排成一条，省略描述文件时，精灵将以 12 FPS 播放。

每种素材使用一个独立文件夹，放在 orb/sprites/, pickup/sprites/ 或 trail/sprites/下。若使用网格排帧或矩形帧，请在 PNG 旁添加 JSON 描述文件。本例的 48 × 32 图像含六个 16 × 16 帧，按从左到右、从上到下的顺序播放。

字段可用值作用
imagePNG 文件名选择同一文件夹中的图像。若只有一个 PNG，可自动识别文件名。导出的图集使用 meta.image 指定图像。
name
nameKey		文本设置固定名称或 Minecraft 翻译键，显示在素材选择器中。导出的图集请在图集设置中填写这些字段。
frameWidth
frameHeight		正整数，单位为像素宽度和高度都要填写。PNG 的宽和高必须分别是帧宽和帧高的整数倍。
frames1–1,024 帧使用网格时，指定要逐行播放的格数。使用图集时，按播放顺序用数组或对象列出帧。
fps大于 0，最大 1,000帧率。未指定每帧时长时，默认以 12 FPS 播放。
loop布尔值，默认 true控制序列图是否循环。替换经验球本体的精灵在显示期间始终循环，拾取精灵始终只播放一次。
pivot[x, y]，以原帧像素为单位锚点相对于原始帧的位置，默认为帧中心。

粒子发射器

设置粒子的生成时机、不同粒子之间的差异，以及发射后的运动方式。

至少启用一种发射方式。可以设置大于零的发射速率、按移动距离发射，或在指定时刻集中发射。将几种方式组合起来，可以先闪现一簇粒子，再持续发射。距离以方块为单位，Y 轴正方向朝上。

字段可用值作用
rate0–128 粒子/秒按时间持续发射。设为 0 可关闭这种发射方式。
distance0.01–64 方块每移动指定距离就发射一次，适合沿经验球的飞行路线等距排列粒子。
bursts最多 16 波，每波为 {time,count}time 表示从开始到发射该波的秒数，范围为 0–30。count 表示该波的粒子数量，范围为 1–64。
direction非零向量 [x,y,z]发射方向会归一化，默认为 [0,1,0]。每个分量的范围为 −1,000,000 至 1,000,000。

方案包与高级效果

一个方案包可以包含一个或多个方案及其使用的外观素材。2.1.0 的可选特效合集包含 24 个方案，例如「蝶群归形」「溪流鱼群」和「墨迹落印」。

安装或更新 ZIP 方案包

  1. 从这里下载 ZIP 文件： 示例页面。
  2. 选择 方案 → 打开方案包文件夹，将 ZIP 文件放入 config/xp_orb_trails/packs/。请保留 ZIP 压缩格式。
  3. 选择 文件方案 → 重新加载文件，然后选择带有该 ZIP 文件名的方案。更新时，用同名 ZIP 替换原文件，重新加载并再次应用方案。

先选一个触发条件符合预期的方案，复制其 JSON 和外观素材。每次只改一个值，再进入世界查看效果。 特效合集指南 列出了全部 24 个方案的触发条件。

经验球本体与拾取
使用 advanced.body 设置移动中的经验球本体，使用 advanced.pickup 设置拾取时的反应。例如「春日飞羽」让小鸟悬停或滑翔，拾取时撒出一阵花瓣。
尾迹与场景条件
使用 advanced.trail 设置尾迹形状，使用 advanced.scene 设置对附近经验球、方块、水或声音的反应。「潮汐水镜」方案演示了如何产生水面涟漪。
工坊与光学效果
使用 advanced.workshop 制作贴花、精灵碎片或轨迹交叉等效果。例如「墨迹落印」会在地面留下墨迹，在水面留下圆环。要了解光照或热折射，可查看以下字段： advanced.optics。「萤石信标」和「流火蜃景」均有示例。

查看 2.1.0 扩展参数表，可按效果类型或 JSON 字段名查找范围和默认值。

给方案添加译名

使用同一个 nameKey 将方案与 Minecraft 资源包中的译名关联起来。例如，在方案中填入 my_pack.profile.moonwake，然后在 assets/my_pack/lang/en_us.json 中填写英文译名，在 assets/my_pack/lang/zh_cn.json中填写中文译名。把资源包放入 Minecraft 的资源包文件夹并启用，玩家就能通过游戏语言切换显示名称。使用固定的 name 则可以让各语言显示同一个名称。

经验球、尾迹和拾取图集也支持译名。规则图集在描述文件的根节点写 nameKey，打包图集则写在 meta.pixelfx 中。只有 PNG 的素材会按 sprite.xporbtrails.<目录名> 查找翻译。升级到 2.1 后，旧内置文件和官方示例保留的原版英文名会随游戏语言切换。你自己改过的名称会按原样显示。

color

color

color

color

workshop · 墨迹（ink）

type 为 ink 时，可以用命名发射器组合效果。例如“墨迹落印” 在碰到固体时留下贴花，在碰到水面时画出涟漪。ink 与 events 使用相同字段，可在同一预设内并用。

JSON 字段取值与默认值作用

ink / events · 发射器字段

以下字段写在 emitters.<名称> 对象中。三种粒子都能设置数量、寿命、尺寸、颜色和淡出。贴花与光环还需要由事件连接传入命中表面的朝向。

JSON 字段取值与默认值作用
kindparticle、decal、ring，默认 particleparticle 会移动。decal 在命中表面绘制方形贴花。ring 在表面绘制向外扩张的环形轮廓。
count整数 1–64，默认 1每次触发该发射器时生成的数量，根发射器和事件触发的子发射器都适用。
lifetime整数 1–200 刻，默认 18最大存在时间，到期触发 death。移动粒子耗尽碰撞次数时也会提前结束。
fadeTicks整数 0 至 lifetime 刻，默认 max(1, round(lifetime × 0.35))生命末段线性淡出的持续刻数。设为 0 时到消失前均保持原透明度。
size0.004–3 格，默认 0.065控制移动粒子或贴花的尺寸。光环半径从该值的 5% 增至 50%。子粒子可继承父粒子的尺寸。
color#RRGGBB，默认 #FFFFFF控制粒子颜色或精灵图着色。连接设置了颜色继承时，子粒子采用父粒子的颜色。
spritesprite:orb/name、sprite:pickup/name 或 sprite:trail/name，默认为空字符串可为移动粒子或贴花指定精灵图。贴图不可用时，移动粒子显示为交叉短线，贴花显示为纯色方块。ring 始终绘制几何轮廓。
faceany、floor、wall、ceiling，默认 any限制贴花或光环可以出现的表面。floor 指朝上的面，ceiling 指朝下的面，wall 指侧面。仅用于 decal 和 ring。
velocity[x, y, z]，每轴 −1 至 1 格/刻，默认 [0, 0, 0]初始速度，随后叠加随机偏移和继承的速度。正 y 向上。贴花和光环的位置固定。
spread0–1 格/刻，默认 0.02在初始速度的三个轴上分别加上 −spread 至 +spread 之间的独立随机值。
gravity−0.5 至 0.5 格/刻²，默认 0.005每刻从移动粒子的竖直速度中减去此值，取负值时粒子向上加速。
drag0–1，默认 0.98每刻先将移动粒子的速度乘以此值，再应用重力。设为 1 时完整保留原速度。
collide布尔值。存在 on.collision 时默认为 true，否则为 false检测移动粒子路径上的碰撞。未定义碰撞事件连接时也可手动开启。
collideFluids布尔值，默认 false启用 collide 后，若先撞到流体表面，可触发碰撞事件。若要用 water 或 lava 分支，应在移动的父粒子上开启此项。
bounce0–1，默认 0.55碰撞后沿表面法线方向反弹的速度比例。0 只保留切向速度，1 表示法向分量完全反弹。
maxHits整数 1–16，默认 2启用 collide 时，移动粒子累计碰撞这么多次后消失。最后一次命中先触发 collision，再触发 death。
on对象，默认空按事件组织子发射器连接，支持的键为 birth、collision、death。

ink / events · 事件连接

在 emitters.<名称>.on 对象内，每个事件都对应一个子连接数组。同一次事件可以在父粒子当前位置触发多个不同的发射器。

JSON 字段取值与默认值作用
birth
collision
death		均为可选数组，每个事件容纳 0–8 个连接对象，默认空每个新粒子生成时触发 birth，命中表面后反弹前触发 collision，到期或达到碰撞上限时触发 death。子粒子从该事件发生的位置生成。
emit必填，值为发射器名每个连接对象都要指定同一 emitters 对象内定义的子发射器名。递归连接也受该图的代数、每刻生成数和同时存在数限制。
hit整数 0–16，默认 00 表示不筛选次数。collision 中的 1 只匹配第一次碰撞，2 匹配第二次，以此类推。正数仅可用于 collision，超过父粒子 maxHits 的次数不会触发。
surfaceany、water、lava、solid，默认 any按父粒子当前接触的材质过滤，子粒子生成时会带上该材质。移动粒子下一次移动未命中时清空接触信息。水和熔岩命中需要 collideFluids。

测试与分享

重新加载修改过的文件并再次应用方案，然后重播预览，再进入世界拾取一颗经验球。

菜单里找不到我的文件
检查重新加载的结果和 logs/latest.log。文件方案和绘制特效都必须使用严格的 JSON 格式，并包含 "version": 1。检查素材用途、重复或未知的键，以及十六进制颜色值的拼写。如果修改后的特效或精灵文件无效，菜单可能仍显示上次成功加载的版本。
原版经验球仍然可见
检查 显示原版经验球 选项和外观素材 ID。超出追踪距离或数量上限的经验球可能显示原版本体。关闭原版本体并将外观设为「无」，即可隐藏经验球本体。
精灵图集加载失败
检查帧尺寸、文件名和图集裁剪信息。单张图集最多 1,024 帧，每边不超过 4,096 像素，总计不超过 4,194,304 像素。每个文件夹最多放一个描述文件。素材库最多支持 64 张图集，合计不超过 16,777,216 像素。
大量粒子同时发射时，有些粒子消失了
每个特效最多八个图层，合计可绘制 96 个几何片段。每个圆环、圆弧或辐射形状的副本都会占用多个片段。每个发射器最多保留 64 个存活粒子，绘制上限为 384 个四边形。减少副本或分段数可以让更多粒子保持可见。
如何把自己的外观分享给其他玩家？
将方案 JSON 文件放入 profiles/，将自定义外观素材放入相应用途的目录： orb/, pickup/ 或 trail/。将这些目录放在 ZIP 根目录。一个 ZIP 可以包含多个方案。分享更新时请沿用原文件名。
如何使用 ZIP 方案包？
选择 方案 → 打开方案包文件夹，将 ZIP 文件放入打开的目录。点击 重新加载文件，选择带有方案包文件名的方案。更新时替换 ZIP，卸载时移除 ZIP，随后重新加载并选择方案。
